# HammerFly

Uses Valheim's native flight movement in server-authorized Hammer worlds without enabling debug mode, developer commands, or administrator access.

## Features

- Requires an explicit authorization response from the connected server.
- Disables flight immediately when authorization is removed or the server changes.
- Hides the `fly` command until authorization is granted.
- Supports `fly`, `fly on`, `fly off`, and configurable enable/disable shortcuts.
- Keeps vanilla movement: Space ascends, Left Control descends, and Shift increases speed.

## Installation

| Client required | Server required |
|---|---|
| Yes | Yes, for Hammer worlds only |

See the [full documentation](https://github.com/end3rbyte/LandoriaMods/blob/main/Landoria.HammerFly/README.md).
