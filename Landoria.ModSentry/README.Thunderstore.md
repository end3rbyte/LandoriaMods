# Landoria ModSentry

Strictly validates required and optional client mods before a Landoria server accepts the connection.

- BepInEx GUID validation
- complete version validation
- mandatory SHA-256 validation
- concise player-facing mismatch messages
- complete server-side diagnostics

All other client mods are rejected. ModSentry performs no gameplay cheat detection.
